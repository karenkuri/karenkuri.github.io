UX Research Paper 2025

Storytelling Data Visualization for Technology Roadmaps

Overview

Conducted a user-centered UX research and design study exploring how visual analytics and interactive storytelling can improve the usability and accessibility of Technology Roadmaps (TRMs). Designed and evaluated two interactive prototype interfaces — a dashboard-style layout and a drill-down navigation system — using stakeholder feedback from academic, industry, and public-sector stakeholders. Applied UX evaluation methods including usability testing, task analysis, Likert-scale questionnaires, and correlation analysis. Developed the supporting application using Oracle APEX and SQL databases.

Timeline & Activities

Research Design

Defined research questions on how storytelling and dynamic visualization can improve technology roadmap usability. Developed study protocol and prototype concepts.

Prototype Development

Designed two interactive interfaces in Adobe (dashboard and drill-down). Built the supporting application using Oracle APEX and SQL databases for technology forecasting data.

User Evaluation

Conducted usability testing, task analysis, and Likert-scale questionnaires with stakeholders from academia, industry, and public sector.

Analysis & Findings

Compared user experience across interface designs. Identified which visual storytelling approaches best supported understanding of complex technology relationships.

Dissemination

Findings presented as a conference paper at CHIIR 2025.
